# Workflow Contract Review

## Scope

Branch `fix/anti-slop-evidence-first`: shared delivery/economy/comment/boundary
instructions, regression seeds, and `evals/function-design/scripts/grade_run.py`.
No model invocation, route activation, deployment, or authorization changes.

## Source-of-truth chain

Pinned `scenarios.json` selects the task/oracle. Frozen candidate source and its
optional ledger receive pinned acceptance tests. The existing oracle consumes
that exact temporary workspace; the JSON report binds their digests.

## Generated argv replay

The runbook's CLI is exercised by focused unit tests with a synthetic fixture.
It invokes the oracle through an argv list without a shell. Exit 0/1 records a
graded pass/fail; invalid input exits 2 without claiming success.

## Producer/consumer consistency

Candidate tests do not replace trusted acceptance tests. The candidate is not
edited. Source, judged-input, baseline, task, test, oracle, and helper digests
identify the exact inputs; metadata labels are caller assertions, not attestation.

## Run-set / target / workflow identity consistency

One explicit scenario, candidate snapshot, metadata file, and non-overwritten
report per grade. No inferred latest run, cross-target chain, or model activation.

## Controller / target-local execution locations

One grading host inside an operator-provided disposable sandbox. The subprocess
and timeout are not security boundaries or process-tree isolation guarantees.

## Deployment/runtime discovery

No installer or remote target. Python stdlib plus the existing pinned fixture
checkout; sandbox permissions and resource limits remain the operator's duty.

## Forbidden fallback checks

No filename/mtime discovery, stale-prompt fallback, or candidate-test fallback.
Unknown scenarios, invalid metadata, missing tests, symlinks, zero-test results,
timeouts, and existing report paths cannot silently become successful grades.

## Claim boundaries

Oracle success is a candidate outcome, not model authorship, agent latency/cost,
or a general quality claim. Source size is diagnostic, not a correctness score.
Real model A/B/C trials have not been performed; calibration cannot replace them.

## Findings

Focused local `WorkspaceGradingTests` pass. The full unit suite additionally
contains existing-fixture calibration and anti-slop mutations for repository CI.
No new model routing, hidden runtime dependencies, or changed authorization.

## Decision

submit: policy/evaluation-tool proposal only. Comparative model benefit remains
unmeasured and runtime isolation is explicitly delegated to the grading harness.
