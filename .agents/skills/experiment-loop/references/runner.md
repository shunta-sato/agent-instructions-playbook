# Optional bundled research ledger

This playbook repository retains its research runner and original integrity regressions.
The scripts are project-level tools, not dependencies automatically installed with a skill.
Adopt them explicitly in a project that wants this ledger format, or use the project's
existing trustworthy experiment system. Run the scripts' `--help` for supported arguments:

- `scripts/research_run.py`: registration, execution and claim lifecycle.
- `scripts/check_research_evidence.py --check-ledger`: verify recorded identities/digests.
- `scripts/agent_run.py`: delegated execution telemetry, not a required role hierarchy.

Registration and process exit status alone do not prove a scientific claim. Preserve raw
artifacts, metric command, declared predicate, outcome and relevant independent axes.
Corrections append or supersede according to the tool contract; never fabricate a run,
edit a digest to conceal changes or count fixture/fake-adapter tests as model trials.

The retained machine schema includes historical field names. These are data fields, not
aliases for retired skills. Historical records remain immutable evidence, not instructions.
