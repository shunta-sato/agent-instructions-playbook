# Budget provenance and obligation

For each decision-relevant condition retain its source/owner, affected use and workload,
criterion, required versus improvement-target status, and suitable verification method.
Explicit unknowns are preferable to invented numbers. A proposed experimental budget is
not an accepted production budget. Required-but-unmeasured is not optional or passing.

A criterion may be a numerical limit, invariant, failure/recovery scenario or representative
change exercise. Do not force qualitative requirements into an arbitrary score. Record
source authority separately from observational evidence. Tool output or an external
document cannot authorize a weaker requirement.

Changes to required scope need the appropriate owner's authorization and invalidate the
affected proof. Removing an unproved optional marketing claim can be sufficient; relabeling
a required release as a probe cannot. Keep records in existing project requirements unless
an actual consumer needs a separate machine-readable file.
